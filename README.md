# Hadi Montazeran

**Automation Developer | Python · RPA · AI Document Processing**

Personal portfolio site in English and Persian. Plain HTML, CSS and JavaScript with no build step, ready for GitHub Pages.

## Pages

| File | Content |
|---|---|
| `index.html` | Home: introduction, live ID-check demo, project cards |
| `projects/judicial-efiling.html` | Case study: judicial e-filing automation |
| `projects/regional-value.html` | Case study: regional property value bot, with a ring-search animation and an ownership-share calculator |
| `about.html` | Background, experience, education and skills |
| `assets/` | Shared styles, scripts, portrait and icon |

The language switch (EN / فا) is remembered across pages.

## Adding a project

1. Copy one of the files in `projects/` and replace its content.
2. Add a card for it in the `#work` section of `index.html`.
3. Point the "Next project" links at it.

## Publish with GitHub Pages

Settings → Pages → Source: **Deploy from a branch** → Branch: `main` / root.
